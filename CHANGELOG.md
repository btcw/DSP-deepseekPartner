# Changelog

## 1.0.0 - 2026-06-04

Initial public release of DeepSeek Gateway.

- Cross-platform Tauri desktop app for managing local DeepSeek proxy profiles.
- Anthropic-compatible and OpenAI-compatible local routes.
- Android Studio AI, Copilot-compatible proxy URL, Claude Code, and third-party agent client setup snippets.
- Claude Code compatibility for `thinking.type=adaptive`, reasoning effort mapping, SSE preservation, and thinking/reasoning replay.
- Smooth OpenAI-compatible streaming output for clients that render very small SSE text deltas awkwardly.
- Local redacted request/response logs, copy buttons, profile edit/delete, and one-click start/stop controls.
- macOS `.app/.dmg` and Windows MSI/NSIS release workflow.
